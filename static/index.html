API Endpoints

GET    /api/users              — List all users
GET    /api/users/{id}         — Get user by ID
POST   /api/users              — Create user
PUT    /api/users/{id}         — Update user
DELETE /api/users/{id}         — Delete user

GET    /api/products           — List products (?category=&min_price=&in_stock_only=&page=&per_page=)
POST   /api/products           — Create product

POST   /api/auth/login         — Login ({"username": "admin", "password": "demo123"})
GET    /api/auth/me            — Protected user info (Bearer token)
GET    /api/auth/status        — Auth service status

GET    /api/health             — Health check
GET    /api/docs               — OpenAPI Swagger UI
GET    /api/stream             — SSE streaming demo
GET    /api/bg-task            — Background task demo
WS     /ws/chat                — WebSocket Chat
